# All buttons: Overview

When choosing the right button for an action, consider the level of emphasis each button type provides.

This is an index page that provides an overview of all button types in Material Design 3. Individual button components include:
- Buttons
- Icon buttons
- FAB (Floating Action Buttons)
- Segmented buttons
- And other button-related components

For detailed information about specific button types, refer to their respective component pages.
