# Time Pickers: Guidelines

## Time Picker Variants

Time pickers help users select and set a specific time. There are two main variants:

### Dial Time Picker

The dial time picker uses a circular interface where users rotate a handle to select hours, minutes, and periods (AM/PM).

**Best used for:**
- Setting alarm times
- Selecting calendar event times
- Quick time selection on mobile devices

### Input Time Picker

The input time picker allows users to manually enter a time using the keyboard, showing hours, minutes, and period fields.

**Best used for:**
- Precise time entry
- Accessibility
- Desktop or tablet interfaces

## Usage

Time pickers should:
- Be easily selectable by hand on mobile devices
- Clearly display the current and selected time
- Support both 12-hour and 24-hour time formats
- Provide clear visual feedback during selection

## Behavior

- Users can switch between dial and input modes using the keyboard/edit icon
- Time can be selected by hours, minutes, and period (AM/PM)
- The current time should be visually distinguished
- Selection should be immediately reflected in the picker interface
