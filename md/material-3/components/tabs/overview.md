# Tabs: Overview

Tabs organize content into multiple views within the same context.

## Key features

- Organize related content into separate views
- Allow switching between content without navigation
- Can be primary or secondary
- Support icons and labels
- Scrollable for many tabs

- Primary tabs (main content organization)
- Secondary tabs (sub-content organization)
