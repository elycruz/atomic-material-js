# Tabs: Specs

## Anatomy

- Tab container
- Tab items
  - Label text
  - Icon (optional)
  - Indicator line (active)
  - Badge (optional)

## Color

Tabs use:
- Primary color for active indicator
- On surface variant for inactive labels
- Primary for active label
- Surface for background
