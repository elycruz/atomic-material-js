# Tabs: Guidelines

## Usage

Tabs organize content into logically grouped sections at the same level of hierarchy.

Use tabs for:
- Switching between related content views
- Organizing content in same context
- Flat navigation without hierarchy
- Content at same importance level

Do not use tabs for:
- Navigation between different pages (use navigation instead)
- Main navigation (use app bar or drawer)
- Sequential content (use stepper)

## Anatomy

- Tab container
- Tab items
  - Tab label (text)
  - Tab icon (optional)
  - Indicator (active state)
  - Badge (optional)
- Content area

## Types

### Primary tabs

Used for main content organization
- Clear visual hierarchy
- Fixed at top
- Larger touch targets

### Secondary tabs

Used for sub-content organization
- Less emphasis
- Can scroll horizontally
- Smaller than primary

## Behavior

- Single tab selected at a time
- Click to switch between tabs
- Icon+label or label-only variants
- Scrollable horizontally if many tabs
- Indicator shows active tab
- Disabled state for unavailable tabs
