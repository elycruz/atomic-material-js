# Divider: Guidelines

## When to Use Dividers

Dividers are visual separators that organize content into logical sections. Use dividers to:

- Group related items together
- Create visual separation between content sections
- Provide subtle visual structure without being overly prominent

### Divider Types

#### Horizontal Dividers

Horizontal dividers separate content horizontally and are the most common type.

**Best used for:**
- Separating list items
- Creating breaks between content sections
- Dividing form sections

#### Vertical Dividers

Vertical dividers separate content vertically and are used for side-by-side layouts.

**Best used for:**
- Separating columns
- Creating breaks in horizontal layouts
- Navigation separators

## Usage Guidelines

- **Use sparingly:** Dividers should not clutter the interface
- **Prefer open space:** Use white space instead of dividers when possible
- **Group items:** Use dividers to group related items, not to separate every item
- **Visibility:** Dividers should be visible but subtle, not bold or prominent
- **Consistency:** Apply dividers consistently throughout the design

## Design Considerations

- Dividers should use a subtle color that doesn't draw excessive attention
- Should typically be 1dp in height or width
- Padding around dividers helps with visual separation
- Consider the overall layout and hierarchy when placing dividers

## Do's and Don'ts

- **Do:** Group related items with dividers
- **Don't:** Use dividers to separate every individual item
- **Do:** Keep dividers subtle in appearance
- **Don't:** Use bold or dark colored dividers
- **Do:** Prefer open space over dividers when possible
- **Don't:** Overuse dividers in your layout
