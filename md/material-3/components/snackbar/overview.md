# Snackbar: Overview

Snackbars provide brief messages about app processes at the bottom of the screen.

## Key features

- Appear at the bottom of the screen
- Display brief, transient messages
- Contain a message and optional action
- Automatically dismiss after 4 seconds or when user interacts with action
- Non-intrusive notification method
