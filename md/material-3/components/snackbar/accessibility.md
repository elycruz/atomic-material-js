# Snackbar: Accessibility

## Use cases

Users should be able to:
- Discover snackbar messages
- Interact with action buttons
- Dismiss snackbars

## Interaction

- Snackbar should be announced by screen readers
- Message text should be clear and concise
- Action button should have descriptive label
- Consider longer dismiss time for screen reader users

## Keyboard navigation

- Tab: Move focus to action button
- Enter/Space: Activate action button
- Escape: Dismiss snackbar (optional)

## Labeling

- Message should clearly describe the action
- Action button should describe what will happen
- Use appropriate ARIA roles and properties
