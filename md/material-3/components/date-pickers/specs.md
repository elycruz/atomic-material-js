# Date Pickers: Specs

## Tokens & Specs

Date picker specifications include color tokens, state information, and sizing measurements for implementation.

### Color Roles

Date pickers use the following color roles:
- Surface container high
- Surface
- Primary
- Secondary
- Tertiary

### States

- Enabled
- Disabled
- Hovered
- Focused
- Pressed (ripple)

### Measurements

- Header height: 120dp
- Calendar grid: 7 columns × 6 rows
- Day button size: 40×40dp
- Month/year navigation buttons: 48×48dp
- Input field height: 56dp
