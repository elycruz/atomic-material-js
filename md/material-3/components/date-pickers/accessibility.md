# Date Pickers: Accessibility

## Use Cases

People should be able to do the following using assistive technology:

- Navigate to a date picker
- Select a date or date range
- Navigate between months and years
- Get appropriate feedback when a date is selected

## Keyboard Navigation

| Keys | Actions |
|------|---------|
| Tab | Move focus to date picker elements |
| Arrow keys | Navigate months, years, or dates |
| Enter or Space | Select a date |
| Escape | Close the date picker |

## Labeling Elements

- Date picker containers should have descriptive labels
- Selected dates should be announced to screen readers
- Indicating current date and selected date range clearly

## Focus Management

- Initial focus should be on the current or first available date
- Focus should move logically through the picker interface
- Clear visual indicators of focus state should be maintained

## Touch and Pointer Targets

- All interactive elements should be at least 48×48 CSS pixels
- Touch targets should have adequate spacing to prevent accidental selection
