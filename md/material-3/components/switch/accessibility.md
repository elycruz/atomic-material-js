# Switch: Accessibility

## Use cases

Users should be able to:
- Identify switch state
- Toggle switch state
- Understand what switch controls

## Interaction

- Switch should announce current state to screen readers
- Label should be associated with switch
- Icon should have descriptive alternative text

## Keyboard navigation

| Keys | Actions |
|------|---------|
| Tab | Focus switch |
| Space/Enter | Toggle switch state |

## Labeling

- Switch should have associated label or text
- Label should describe what switch controls
- Use appropriate ARIA roles and states
- If icon present, provide alternative text
