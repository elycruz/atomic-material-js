# Switch: Specs

## Anatomy

- Track (background container)
- Thumb (toggle indicator)
- Icon (optional, inside thumb)

## Color

Switch uses:
- Primary color for on state
- Surface variant for off state
- On primary for on-state icon
- On surface variant for off-state icon

## Measurements

| Attribute | Value |
|-----------|-------|
| Track width | 52dp |
| Track height | 32dp |
| Thumb diameter | 24dp |
| Corner radius | 16dp |
| Icon size | 16dp |
| Touch target | 48dp x 48dp |

## States

- Off (unselected)
- On (selected)
- Off disabled
- On disabled
- Off hovered
- On hovered
- Off focused
- On focused
- Off pressed
- On pressed
