# Switch: Guidelines

## Usage

Switches are used for binary on/off selections.

Use switches for:
- Toggle settings on or off
- Enable/disable features
- Binary choices
- Preference selections

Do not use switches for:
- Multiple selection options (use checkboxes)
- Immediate navigation (use buttons)
- Complex conditional logic

## Anatomy

- Track (background)
- Thumb (toggle circle/indicator)
- Icon (optional)
- Label (recommended)

## States

- Off (unchecked)
- On (checked)
- Disabled (both on and off)
- Hover
- Focus
- Pressed

## Behavior

- Single tap toggles state
- Immediate feedback on interaction
- Icon can indicate state visually
- Should always have associated label
- Accessible via keyboard (Space/Enter)
